# Code Signing & Licensing API Documentation

This document describes the API endpoints and integration workflow for signing binary/file hashes in CI/CD environments and managing device-bound software licenses.

---

## Authentication & Rate Limiting

All endpoints are rate-limited via `RateLimiterFirewall`. Ensure your integration handles standard HTTP rate limit response codes (`429 Too Many Requests`).

---

## Response Format

All API responses follow a unified structure.

### Success Envelope

```json
{
  "success": true,
  "response": {},
  "error": null,
  "metadata": {
    "timestamp": 1786486816.654943,
    "timezone": "Europe/Warsaw"
  },
  "signature": "MEUCIQDx8...[base64-encoded signature]"
}

```

### Error Envelope

```json
{
  "success": false,
  "response": [],
  "error": {
    "code": "ERROR_CODE_STRING",
    "description": "Human-readable error description",
    "data": []
  },
  "metadata": {
    "timestamp": 1786486916.453467,
    "timezone": "Europe/Warsaw"
  },
  "signature": "MEUCIQDx8...[base64-encoded signature]"
}

```

## Code Signing & Key Management

### Get Public Key

Retrieves the application's public key used for local signature verification.

* **Endpoint:** `GET /api/v1/public-key`
* **Response (200 OK):**

```text
-----BEGIN PUBLIC KEY-----\nMIIBIjANBgkqhkiG9w0BAQEFAAOCAQ8AMIIBCgKCAQE...\n-----END PUBLIC KEY-----
```

---

### Sign Hash

Signs a SHA-256 hash generated by a client or CI/CD pipeline. Requires an active device registration tied to a valid license.

* **Endpoint:** `POST /api/v1/sign`
* **Request Body:**

```json
{
  "license_key": "CS-12345-ABCDE",
  "device_id": "c7f59c3d-cfa2-4bf5-88fa-92a21cb03c27",
  "hash": "a591a6d40bf420404a011733cfb7b190d62c65bf0bcda32b57b277d9ad9f146e",
  "algorithm": "sha256"
}

```

* **Response (200 OK):**

```json
{
  "success": true,
  "response": {
    "signature": "MEUCIQDx8...[base64-encoded signature]",
    "signed_at": 1786486816
  },
  "error": null,
  "metadata": {
    "timestamp": 1786486816.654943,
    "timezone": "Europe/Warsaw"
  },
  "signature": "MEUCIQDx8...[base64-encoded signature]"
}

```

* **Error Response (403 Forbidden):**

```json
{
  "success": false,
  "response": [],
  "error": {
    "code": "DEVICE_NOT_ACTIVE",
    "description": "Device is not active or license limit exceeded",
    "data": []
  },
  "metadata": {
    "timestamp": 1786486916.453467,
    "timezone": "Europe/Warsaw"
  },
  "signature": "MEUCIQDx8...[base64-encoded signature]"
}

```

## Integration Workflow for CI/CD Pipelines

To sign binary files during a build process on ephemeral runners (such as GitHub Actions or GitLab CI), follow this workflow:

1. **Activate Device:** Issue a `POST` request to `/activate` at the start of the job to obtain the activation `id` (used as `device_id`).
2. **Hash Target File:** Compute the local SHA-256 hash of the compiled binary or artifact.
3. **Sign Hash:** Send the hash along with your `license_key` and activation `id` to `POST /api/v1/sign`.
4. **Deactivate Device:** Execute a `POST` request to `/deactivate` in a cleanup step to release the device slot.

### Example Script (Bash)

```bash
#!/usr/bin/env bash
set -e

SERVER_URL="https://your-domain.com"
LICENSE_KEY="CS-12345-ABCDE"
FILE_TO_SIGN="./build/app-binary"

# 1. Activate runner device
ACTIVATE_RES=$(curl -s -X POST "$SERVER_URL/api/v1/licenses/$LICENSE_KEY/activate" \
  -H "Content-Type: application/json" \
  -d '{"device_name": "Ephemeral-CI-Runner", "device_identifier": "GitHub-Actions-Runner"}')

DEVICE_ID=$(echo "$ACTIVATE_RES" | jq -r '.response.activation.id')

# Ensure cleanup on script exit
trap 'curl -s -X POST "$SERVER_URL/api/v1/licenses/$LICENSE_KEY/deactivate" -H "Content-Type: application/json" -d "{\"device_id\": \"$DEVICE_ID\"}"' EXIT

# 2. Calculate file hash
FILE_HASH=$(sha256sum "$FILE_TO_SIGN" | awk '{print $1}')

# 3. Request signature
SIGN_RES=$(curl -s -X POST "$SERVER_URL/api/v1/sign" \
  -H "Content-Type: application/json" \
  -d '{
    "license_key": "'"$LICENSE_KEY"'",
    "device_id": "'"$DEVICE_ID"'",
    "hash": "'"$FILE_HASH"'"
  }')

SIGNATURE=$(echo "$SIGN_RES" | jq -r '.response.signature')
echo "$SIGNATURE" > "$FILE_TO_SIGN.sig"

```
