# Code Sign App API

## Authentication

API requests do not require token-based authentication. Protection is provided by the [rate limiting system](https://www.google.com/search?q=rate-limiting.md).

## List of Endpoints

### Get Public Key - [GET] /api/v1/public-key

Retrieves the application's public key used for local signature verification.

#### Successful Response:

```json
{
  "success": true,
  "response": {
    "public_key": "-----BEGIN PUBLIC KEY-----\nMIIBIjANBgkqhkiG9w0BAQEFAAOCAQ8AMIIBCgKCAQE...\n-----END PUBLIC KEY-----",
    "algorithm": "sha256WithRSAEncryption"
  },
  "error": null,
  "metadata": {
    "timestamp": 1786487178.538961,
    "timezone": "Europe/Warsaw"
  },
  "signature": "MEUCIQDx8...[base64-encoded signature]"
}

```

#### Errors:

* `INTERNAL_SERVER_ERROR` - Unable to retrieve public key

---

### Sign Hash - [POST] /api/v1/sign

Signs a SHA-256 hash generated by a client or CI/CD runner. Requires an active activation ID linked to a valid license.

#### Body Requirements:

* `license_key` (string, required)
* `activation_id` (string, required)
* `hash` (string, required)

#### Successful Response:

```json
{
  "success": true,
  "response": {
    "signature": "MEUCIQDx8...[base64-encoded signature]",
    "algorithm": "sha256WithRSAEncryption",
    "signed_at": 1786487178
  },
  "error": null,
  "metadata": {
    "timestamp": 1786487178.538961,
    "timezone": "Europe/Warsaw"
  },
  "signature": "MEUCIQDx8...[base64-encoded signature]"
}

```

#### Errors:

* `LICENSE_NOT_FOUND` - License key not found
* `LICENSE_INACTIVE` - License key is inactive
* `LICENSE_EXPIRED` - License key is expired
* `ACTIVATION_ID_MISSING` - Activation ID is missing
* `ACTIVATION_NOT_FOUND` - Activation not found or inactive
* `HASH_MISSING` - Hash parameter is missing
* `INTERNAL_SERVER_ERROR` - Internal server error during signing operation
